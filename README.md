# 格式匠研究资源

格式匠「研究资源」页面的公开数据源。内容由官方维护，YAML 是唯一数据源，`catalog.json` 与本文件由脚本生成。

## 分类

- **学习资源**：课程、教程与研究方法学习资料。（0 条）
- **研究工具**：提升检索、阅读、整理与写作效率的工具。（0 条）
- **研究类 skill**：可复用的研究技能与工作流。（3 条）
- **研究类 MCP 服务**：面向研究场景的 MCP 服务与连接入口。（1 条）
- **期刊与会议**：期刊、会议与投稿相关官方网站。（1 条）
- **高校与研究机构**：高校、研究机构与学术服务平台。（0 条）

### 研究类 skill

- [grill-me](https://github.com/mattpocock/skills/tree/main/skills/productivity/grill-me) - 访谈式 skill：对计划或设计逐层追问，每轮只问一个问题并给出推荐答案，按决策树深度优先推进，直到每个分支都达成共识。适合在动手前把需求边界、取舍与依赖问清楚。
- [grill-with-docs](https://github.com/mattpocock/skills/tree/main/skills/engineering/grill-with-docs) - 以项目文档为锚点的追问 skill：用 CONTEXT.md 的词汇表校准术语，用 docs/adr/ 中已记录的决策挑战新方案，用户表述与代码不一致时当场指出，术语定稿时同步更新 CONTEXT.md。
- [humanizer](https://github.com/blader/humanizer) - 写作修改 skill：识别并清除 AI 生成文本的痕迹，包括空泛拔高、宣传腔、以 -ing 结尾的空洞分析、模糊引证、破折号滥用、三段式排比与 AI 高频词，按维基百科「Signs of AI writing」的条目逐类改写。
